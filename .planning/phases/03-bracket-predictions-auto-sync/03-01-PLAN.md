# Plan 03-01: Predictions Auto-Sync Logic and UI

Implement predictions auto-syncing, confirmation overlays, lock visual treatments, and verification test suites.

## Proposed Changes

### Predictions State Hook
- **File**: [useBracketPrediction.ts](file:///c:/Off%20work/wc2026/hooks/useBracketPrediction.ts) [MODIFY]
  - Add `syncWithRealTournament` function:
    1. Fetch `/api/fixtures` to get actual matches.
    2. Sync all group rankings with database standings (group.teams FIFA placement).
    3. Auto-allocate the database's actual third-place wildcard teams to `thirdPlaces`.
    4. Construct a new `knockoutPicks` mapping:
       - For each finished knockout match (73 to 104) with status `FINISHED`, calculate the actual winner (including extra-time and penalties) and set `knockoutPicks[matchNumber] = winnerId`.
       - For unplayed matches, retain the user's custom picks if the predicted team is still alive and qualified for that specific matchup slot. Otherwise, clean them up to ensure valid bracket paths.
    5. Save the updated states to `localStorage` and trigger the API save (`submitBracket`) to synchronize with the backend DB remote profile.

### Visual Predictor Dashboard
- **File**: [BracketChallenge.tsx](file:///c:/Off%20work/wc2026/components/bracket/BracketChallenge.tsx) [MODIFY]
  - Inject the "Sync with Real Knockouts" action button next to the "Reset Bracket" button in the header toolbar.
  - Add a rotating animation on click (`animate-spin` while executing).
  - Add a glassmorphism confirmation modal overlay prompting the user before execution: *"Warning: This will overwrite your predictions for completed matches with actual results and adjust downstream pathways where matchups have changed. Do you wish to proceed?"*.
  - Pass down an `actualFinishedMatches` set (or map) from the hook, so cards for played matches render read-only styles (gold lock indicator, lower opacity, disabled click handlers).

## Verification Plan

### Automated Tests
- Create a test file `tests/hooks/useBracketPrediction.test.ts` (using Vitest) verifying:
  - Syncing group stage rankings to actual standings correctly updates states.
  - Finished knockout matches populate the correct winner team ID.
  - Draw matches resolved via Extra-Time or Penalty Shootout identify the correct winner.
  - User custom selections for unplayed matches are preserved when matches are unaffected, and deleted when they are invalidated by intermediate results.

### Manual Verification
- Deploy local dev server and test:
  - Clicking "Sync with Real Knockouts" triggers the warning modal.
  - Declining cancels the action; accepting runs the sync successfully.
  - Toast alerts notify the user of execution results ("Successfully synced with live tournament!").
  - Visually inspect lock icons and disabled pointer states on completed matches.
